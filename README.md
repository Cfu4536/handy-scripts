# HandyScripts · 随手脚本

一个个人自用的脚本与配置集合，集中维护 MusicFree 插件、订阅清单、桌面主题和浏览器用户脚本。按用途分目录组织，便于配置、更新和维护日常使用的小工具。

当前项目由静态 JSON 配置、MusicFree 插件、桌面主题和浏览器脚本组成，没有独立的 HTTP API、后端服务、依赖清单或统一构建流程。MusicFree 插件使用客户端提供的内置模块，桌面主题使用 ZIP 格式打包。
